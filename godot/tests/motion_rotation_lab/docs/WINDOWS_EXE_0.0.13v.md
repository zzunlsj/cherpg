# CheRPG Motion Lab 0.0.13v — Windows 실행 안내

- Godot 4.7.2 / Windows 64비트 / 제작자·회사 파일 정보: CheRPG
- 기존 0.0.12v의 100m×100m 평지, 2m×2m 판면, 시험 시설, F/R/Shift/O 키, 모션 및 앵커 동작은 그대로 유지합니다.

## 카메라 개선
- 마우스를 **위로** 움직이면 카메라가 점차 올라가며, 최대 **정확히 90°(수직 위에서 아래를 보는 탑뷰)**까지 허용합니다.
- 마우스를 아래로 내리면 카메라 고도가 낮아집니다. 하한은 수평보다 약 25° 낮은 각도입니다.
- HUD에서 카메라 상승각을 0~90° 및 음수 각도로 확인할 수 있습니다.
- 90°에서 발생하는 Godot `look_at`의 World UP 평행 문제를 막기 위해 카메라 방향을 안정적으로 구성했습니다.
- WASD는 카메라의 **수평 회전각(yaw)**을 사용하므로, 90° 정수직에서 카메라 시선의 수평 성분이 0이 되어도 이동 방향이 초기화되거나 바뀌지 않습니다.
- 폰의 행마 방향은 카메라 각도·신체 방향과 독립적인 값으로 유지합니다.

## 주요 조작
WASD: 카메라 기준 이동 / Shift: 대시 / Space: 점프 / F: 앵커 설치·회수 / 설치 중 A/D: 행마 방향 ±90° / R: 누르는 동안 설치 공간 홀로그램 / O: 현재 시험 지점 리셋 / 1~9·0: 시험 위치 선택 / 마우스: 카메라 / Esc: 포인터 전환 / F1: 판면 강조.

## 직접 플레이로 확인할 항목
1. 카메라를 위쪽으로 회전해 HUD에 90°가 표시되고 바닥을 정확히 내려다볼 수 있는가?
2. 90°에서 계속 마우스를 움직여도 화면이 뒤집히거나 회전 방향이 역전되지 않는가?
3. 카메라를 45°, 89°, 90°로 바꾸면서 W/A/S/D를 누를 때 수평 이동 방향이 급격히 바뀌지 않는가?
4. 바닥 타일 경계, 앵커 설치 홀로그램, 대시/점프 동작이 정상적으로 보이는가?

자동 빌드는 짧은 파싱·시작 검사 및 EXE 생성·파일 형식/회사 메타데이터 확인만 수행하며, **1분 이상 주요 플레이/품질 테스트는 사용자가 직접 수행**합니다. 디지털 서명은 없으므로 Windows 보안창에 '알 수 없는 게시자'가 나타날 수 있습니다.
