# CheRPG 0.0.7v — 정사 반영 / 별도 Godot 모션 테스트 맵

이 폴더는 본편과 독립적인 임시 테스트 맵이다. **주요 Godot 플레이 테스트는 사용자 담당**이므로 이 변경은 Godot 실행 테스트 합격을 주장하지 않는다.

## 기준 및 충돌 우선순위
- 《체스 RPG 세계관 설정집》 (2026-09-30): ① 세계의 물리법칙과 행마의 본질, ⑩ 회전 타일과 기술 체계.
- 《CheRPG 프로젝트 대화 통합기록》 (2026-10-13): 07. 3D Godot 플레이·회전 장치 및 12. 충돌하는 과거 지시와 최종 우선순위.
- 최근 명시적 수정(2026-10-07)이 과거 설정과 충돌하면 최근 지시를 우선한다. 휴대형 방향 전환 장치는 몸을 돌리지 않고 **행마 기준 방향값만 변경**한다. 고정형 회전 타일은 실제 회전 시설로 별도 유지한다.

## 적용
| 정사 원칙 | 0.0.7v 구현 |
|---|---|
| 판면은 보이지 않고 지형과 중첩 | 2m 타일 좌표를 독립 계산. F1일 때만 디버그 표식 표시 |
| 칸 내부 신체 활동은 자유 | W/S/A/D 2축 이동 허용. 원본 Unity 입력 보간·4/6m/s 유지 |
| 칸 사이 자발 이동에는 행마 | 표준 폰의 현재 행마 방향으로 한 칸 전진 경계만 허용, 옆/뒤 경계 통과는 저항 |
| 신체 방향과 행마 기준 방향 분리 | Z/C 키로 신체만 회전; 시각적 몸 yaw와 heading_index 독립 |
| 점프도 판면 위의 행마와 공존 | 기존 가변 점프/착지 유지, 공중에서도 같은 경계 제한 |
| 외부 힘에 의한 강제 이동은 별개 | apply_forced_displacement(delta_world) 제공, 행마 방향값은 유지 |
| 휴대용 방향 앵커가 현재 칸에 연결 | 장치 전개 전에 링/받침이 칸 안에 들어가는지 확인하고 현재 칸을 잠금 |
| 최신 휴대형 장치 수정 | 앵커 전개 후 행마 기준만 90도 변경. 폰 몸과 타일은 회전하지 않음 |

## 한계 및 개발용 가정
- 링 지름, 발판 크기, 경사 속도 계수 등 모델 치수는 테스트용 구현값이지 정사에서 확정된 수치가 아니다.
- 본편 행마식 전체, 공격, 승진, 왕정석 권한 검증, 스킬 및 지역 예외와 턴/행동력은 이 단독 테스트 맵에서 구현하지 않았다.
- 표준 폰은 칸 안쪽에서 뒤나 옆으로 움직일 수 있으나 칸 밖으로 뒤나 옆으로는 넘어가지 않는다.
- 외력 API는 별도 이동 경로를 제공하는 수준이고 넉백 피해/충돌 반동 시스템은 아니다.
- 레인 시작점을 각 레인의 (0,0) 판면 칸 중앙으로 임시 사용한다. 본편 월드에서 실제 판면 좌표로 교체해야 한다.
- 이 변경에는 Godot 런타임/플레이 테스트 결과가 없다. 코드를 읽는 검사만 진행했고, 1분 이상 테스트는 사용자에게 위임한다.

## 직접 검수할 항목
1. 평지에서 W/S/A/D로 현재 칸 안을 자유롭게 이동할 수 있는가 (F1 표시로 좌표 확인)?
2. 북쪽으로 다음 칸에 전진한 뒤 뒤/옆 칸 경계 통과가 저항으로 막히는가?
3. Z/C 키로 몸만 돌려도 행마 기준 방향이 그대로인가?
4. 현재 칸 중앙에서 R→E→Q가 가능하고 가장자리에서는 링 전개가 거부되는가?
5. 8°/15°/요철/30° 지형에서 걷기·달리기·점프·접지가 올바른가?
6. 점프 도중 행마를 우회해 옆칸을 넘거나 전개 중 이동할 수 없는가?

단시간 코드 검사는 python tests/test_canon_rules_quick.py, python tests/test_source_feel.py. **실제 Godot 플레이 검수를 대체하지 않는다.**
