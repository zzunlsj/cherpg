# CheRPG 0.0.16v — 벽 상단 턱 넘기, 파츠 충돌, 지형 적응 애니메이션

Godot 4.7.2, Windows x64, 회사 파일 메타데이터: CheRPG. **본편과 분리된 독립 테스트장**.

## 벽 상단 기능
- **Ctrl + W**를 누른 상태로 `cherpg_grabbable`로 표시된 30°~90° 경사를 등반한다.
- 수직벽 상단에 도달하면 올라갈 상부 발판의 지면 법선, 목표 위치에서의 완전한 캐릭터 캡슐 통과 가능 여부, 현재 4m 판면 규칙을 모두 확인한다.
- 통과하면 **REACH(손 걸기) → PULL(몸 끌어올리기) → SWING(무릎/다리 넘기기) → LAND(두 발 착지)** 약 1.16초의 단계별 턱 넘기로 진행한다.
- 턱 넘기 동안은 일반 WASD/점프·등반 이동을 잠시 일시정지하고 루트 이동을 해당 애니메이션 단계가 소유한다. 각 구간에서 물리 충돌 검사(`move_and_collide`) 및 판면 이동 검사를 반복한다.
- 충돌이 연속해서 막히거나 잘못된 판면 이동이면 턱 넘기를 취소한다. 캐릭터를 벽 안으로 순간이동시키는 방법을 사용하지 않는다.
- 현재 수직벽 실험 시설에는 상부 착지 플랫폼이 있으며, 임의 형상 절벽에 대한 완전 자동 경로탐색 기능은 아직 없다.

## 파츠별 충돌 구현 범위
- 전신의 **모든 기본도형 MeshInstance3D 파츠**에 각자 위치와 크기를 따라가는 `Area3D` + `CollisionShape3D` 충돌 검사 볼륨을 추가한다.
- 실시간으로 외부 지형(물리 layer 1) 및 자신의 다른 파츠(layer 4)에 대한 접촉을 조사하고, 비정상 겹침을 유발한 관절 자세는 직전 안전 자세로 보간하여 되돌린다.
- 어깨-상완, 고관절-허벅지, 무릎-정강이처럼 연결 관절에서는 의도된 맞닿음/겹침을 허용한다. 팔꿈치를 독립적인 힌지로 분리하여 당기기/디딤 연출에 사용한다.
- 주 몸통용 CharacterBody3D 캡슐은 높이를 1.60m로 높여 1.55m 기본도형의 모자/머리도 충돌범위에 포함한다. Shift 웅크림·Ctrl 달리기·앵커 입력은 유지한다.
- **제약**: 이는 정밀 메시-메시 무관통 물리나 모든 충돌 조합에 대한 절대 보증이 아닌, 기본도형 볼륨 기반의 *보수적인 접근 충돌/관절 보정 시제품*이다. 작은 관통, 가까운 관절의 의도된 접촉, 빠른 애니메이션 중 실제 모양과 충돌 볼륨 차이는 별도 확인 필요.

## 지형 적응
- 걷기·달리기·웅크리기는 지면 기울기/지면법선에 맞춰 몸의 상하 기울기, 발목 기울기, 무릎 굽힘 및 발 미끄러짐 보정.
- 두 발마다 레이캐스트를 해 접촉 지형의 높이와 법선을 읽고, 발이 땅속으로 파고들지 않도록 무릎 굴곡과 기본도형 높이를 작은 범위에서 보정.
- 점프는 상승/하강, 등반은 붙잡은 표면 법선, 턱 넘기는 상단 착지면 확인과 각 상태별 손·무릎 포즈를 사용한다.
- 이 시제품에는 완전한 2-bone IK/별도 래그돌 시뮬레이터/모션캡처가 없다.

## 조작
**WASD** 카메라 기준 이동 · **Ctrl** 누르는 동안 달리기(최대 6m/s), **Ctrl+W** 잡을 수 있는 벽 등반 · **Shift** 누르는 동안 웅크리기 · **Space** 점프 · **I** 판면 *행마 이동 제한만* ON/OFF(4m×4m 바닥 타일 무늬 유지) · **F** 누르는 동안 앵커 공간 미리보기, 놓으면 설치·회수 · 설치 완료 시 **A/D** ±90° 방향 변경 · **O** 현재 지점 리셋 · **1~9,0** 시험 지점 이동 · 마우스 최대 90° 카메라.

## 검수 책임
코드·짧은 시작·Windows 빌드의 성공과 실플레이 품질은 별개다. **1분 이상 걸리는 주요 플레이 테스트는 사용자가 직접 수행**. 벽 상단 턱 넘기의 충돌 차단/취소, 각 부위의 벽·몸통 관통, 경사 위 착지·발 미끄러짐이 이번 검수의 핵심이다. Windows 디지털 코드서명 인증서는 아직 없다.
