# CheRPG Motion Lab 0.0.21v — 애니메이션 크기 변형 제거

Godot 4.7.2 / Windows x64 / 파일 속성 회사 정보 CheRPG.

## 변경 사항

- **웅크리기:** 기존 `avatar.scale.y = lerpf(1.0,0.67,crouch_blend)` 전신 압축 제거. 상체·목·머리·양팔을 새 허리 피벗 `RIG_UpperBodyWaistHinge_NoScaling`에 붙이고, **상체 회전 + 골반 낮춤 + 무릎 굽힘**으로 자세 구현.
- **걷기, 달리기, 점프, 등반, 벽 턱 넘기, 공격:** 각 메시의 길이·너비·높이는 최초 상태와 동일. 모션은 관절 피벗 회전 및 위치 이동으로 구현.
- **관절 충돌:** 상체 허리 피벗도 이전 안전 자세로 복귀하는 관절 충돌 보정에 포함. 기존 무릎 역방향 꺾임 방지 유지.
- **휴대용 회전장치:** 동적 크기 변경 대신 고정 크기 수납/전개 링을 교차 페이드. 네 레일은 부품 위치를 이동시키고, 앵커 막대는 **고정 길이의 중첩된 슬라이딩 튜브**로 전개. 발판은 크기를 유지한 채 지면 법선에 맞춰 회전.
- 수납 중 회전장치는 몸통/골반과 함께 **이동**하며, 앵커 설치 중에는 지면 기준 위치 유지.
- 기본도형 캐릭터 외형과 전체 테스트장·입력 체계는 유지.

## 검사 범위

`tests/test_rigid_animation_source_quick.py`: 런타임 파츠/장치 스케일 변경 코드 차단.

`tests/check_rigid_animation_geometry_0.0.21v.gd`: Godot 씬에서 8종 모션(걷기, 달리기, 점프, 등반, 턱 넘기, 웅크리기, 공격, 앵커)을 짧게 구동하며 각 메시의 scale 및 원래 Mesh AABB 치수를 비교하는 테스트.

**한계:** 고정 크기 검사는 임의 자세에서의 파츠 간 충돌, 모든 지형·애니메이션의 자연스러움, 정확한 발 IK를 입증하지는 않습니다. 장시간 플레이/영상 품질 검수는 사용자 담당입니다. 장치의 두 링은 변형되지 않는 대신 개폐 중 교차 페이드됩니다.

## 조작법 유지

WASD 카메라 방향 이동, **Shift=웅크리기**, **Ctrl=달리기/등반**, Ctrl만 유지 시 벽에 매달려 정지, 등반 중 Ctrl+W/S 상하·Ctrl+A/D 좌우, **F=앵커 미리보기/설치**, **I=4m 논리 판면의 이동 제한 ON/OFF**(타일 패턴 계속 표시), O 리셋, Space 점프, 90° 카메라 탑뷰.

Windows 파일에는 `CompanyName=CheRPG`를 기록하되 디지털 코드서명은 미적용입니다.
