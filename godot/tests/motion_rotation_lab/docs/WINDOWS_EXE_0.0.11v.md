# CheRPG 0.0.11v — Windows 테스트 맵 실행 안내

**Godot 4.7.2 / Windows x64 / 제작자: CheRPG (파일 VERSIONINFO).**

이제 맵은 **다섯 개의 끊어진 섬이 아니라 70m 길이의 단일 연결 지형**이다. 평지 → 8° → 15° → 요철 → 30°를 중간 로딩 없이 걸어서 연결할 수 있다.

- 2m 판면 칸: 옅은/진한 색을 번갈아 칠하고 각 경계에 어두운 선을 상시 표시한다. **이 패턴은 테스트 시각화**다. 정사 세계에서 실제 흑백 지면이 있다는 설정은 아니다.
- W/A/S/D 또는 방향키: **카메라의 수평 정면을 기준**으로 이동. 원본 `pawn_player.cs` 입력의 10/s 스무딩, 기본 4m/s, Shift 달리기 6m/s 및 2배 가속 특성 유지.
- 왼쪽 클릭: `attack` 트리거에 대응한 간단한 팔 휘두르기. 아직 적 공격/판정/피해 없음.
- Space: 점프(짧게 누르면 낮은 점프), 상승/하강/착지 별도 관절 모션.
- R/E/Q: 회전장치 전개/행마 방향만 변경/회수.
- 1~5: 같은 연속 지형의 각 구역 출발 지점으로 바로 이동. **걸어서 모든 구역 이동 가능**.
- F1: 판면 경계 강조, Z/C: 몸만 회전, T: 현재 구역 출발 지점 재설정, 마우스: 카메라 조절, Esc: 마우스 잠금 전환.

월드 행마는 타일 **내부 자유이동 / 다른 칸으로 자발적으로 넘어갈 때 폰 행마식 검사**를 유지한다. 연출은 모델 세부 조형 없이 기존 기본도형의 관절만 사용한다.

### 사용자가 직접 수행할 주요 플레이 테스트
1. 평지부터 30° 지역까지 맵 연결에 끊김/투명면/충돌 틈이 없는지 확인.
2. 위쪽 시점에서도 2m 격자 경계가 보이고, 1~5 구역마다 타일 정렬이 일치하는지 확인.
3. WASD·방향키·Shift·마우스 클릭 입력, 카메라 회전에 따른 이동 축을 비교.
4. 달리기↔걷기 전환, 경사 이동, 점프 상승/착지의 관절 연결과 지면 접촉을 검수.
5. R→E→Q 방향장치 작동 및 판면 규칙 제한을 확인.

**장시간(1분 이상) 플레이/품질 테스트는 사용자 담당**. 자동 빌드는 에디터 임포트 및 EXE 생성, 빌드 파일의 PE 헤더/회사 메타데이터 검사까지만 수행한다.

파일 속성에 회사 `CheRPG`를 기록하지만 **디지털 서명 인증서가 없어 Windows 보안창의 게시자는 '알 수 없음'일 수 있다.** 서명된 게시자 표시는 인증서 서명이 별도로 필요하다.
