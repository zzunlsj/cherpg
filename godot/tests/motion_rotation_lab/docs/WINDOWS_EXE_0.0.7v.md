# CheRPG — Windows PC 테스트판 0.0.7v

이 폴더의 CheRPG-MotionLab-0.0.7v.exe를 더블클릭해서 실행하세요. Windows 10/11 x64용 Godot 4.5.2 독립 테스트 맵입니다.

## 실행
- 별도의 Godot 설치는 필요하지 않습니다.
- 본편과 분리된 **테스트 맵**이며, 본편 세이브나 월드 파일을 수정하지 않습니다.
- 게임 데이터(PCK)는 EXE 안에 포함되어 있으므로 함께 배포할 추가 PCK 파일이 필요하지 않습니다.
- 디지털 서명을 진행하지 않은 개발용 파일입니다. Windows SmartScreen 경고가 표시될 수 있으니 다운로드 출처(GitHub CheRPG PR #2)를 확인하세요.

## 조작
- W / A / S / D: 한 칸 내부에서 자유 이동. **칸 경계**에서는 현재 폰 행마 방향 전진만 허용.
- Shift: 달리기 / Space: 점프 (짧게 누르면 낮게 뛰기).
- Z / C: **신체 방향만** 좌우 회전. 행마 기준 방향은 그대로 유지.
- R: 회전장치 전개, E: 행마 방향 변경, Q: 앵커와 링 회수.
- 1~5: 평지·8°·15°·요철·30° 경사 테스트 맵.
- F1: 판면 격자 표시, T: 출발점으로 이동, 마우스: 카메라 회전, Esc: 마우스 포인터 전환.

## 유의사항
- 기본도형을 유지한 조작 및 세계관 규칙 시험용 시제품입니다.
- 실시간 지면 접촉, 도약 시 판면 경계, 회전장치 4개 앵커를 직접 플레이하며 확인해 주세요.
- 이 빌드 작업에서는 **사용자가 맡기로 한 1분 이상의 주요 플레이/품질 테스트를 실행하지 않았습니다.**
- 컴파일 및 Windows EXE 파일 생성·파일 헤더 확인만 수행했습니다.
- 버전: 0.0.7v, Godot 4.5.2, Windows x86_64, 독립 테스트 맵.
