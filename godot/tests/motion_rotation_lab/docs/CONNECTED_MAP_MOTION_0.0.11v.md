# CheRPG 0.0.11v — 연결 지형 · 가시 판면 · 원본 C# 입력 · 관절 모션

## 실제 소스 변경
- `scripts/test_lane.gd`: 원래 5개 서로 떨어진 지형을 **하나의 연속 높이장, 하나의 콜리전**으로 대체. 전체 길이 70m, 너비 10m. 경사 전환부는 1.2m 구간 부드러운 적분 램프를 사용하고 요철 영역은 경계에서 높이 0으로 페이드한다. 스폰 지점은 각각 경사대 안쪽으로 14m 간격(10m, -4m, -18m, -32m, -46m Z)에 놓는다.
- 상시 보이는 **2m 정사 판면 테스트 표시**: ShaderMaterial로 세계 XZ 위치에 정렬해 두 색 대비 + 어두운 선을 그린다. F1 경계 강조. 실제 세계의 보이지 않는 판면을 개발 편의상 드러낸 것이며 영구 지형 칠이 아니다.
- `scripts/motion_lab.gd`: 오브젝트를 5개 생성하던 로직 제거. 단일 terrain 객체만 사용. 번호키는 같은 맵 내 순간이동. 게임 중 지역 상태도 위치로 산출.
- `scripts/pawn_controller.gd`: 기본형 몸체 유지. 실제 속도 기반 걷기·달리기 보폭 연속 혼합, 지형 기울기에 따른 무릎/발/상체, 점프 상승·하강·착지 구간 자세, 짧은 왼클릭 팔 스윙.
- 원본 유니티 `pawn_player.cs`: WASD/방향키, LeftShift, LMB(attack), 원본 10/s 입력 보간 및 4/6m/s 걷기·달리기, 달리기 가속 x2. Unity Rigidbody2D `AddForce` 20000을 Godot CharacterBody3D에 직접 옮기는 것은 불가능하므로 기존 보정 가속을 유지.
- 카메라 상대 이동, 2m 칸 경계 행마 제한, 점프 독립 기능, 방향장치 4개 앵커의 접지 동작을 유지.

## 한계
- 배치된 시각 그리드는 논리 판면과 동일한 2m 규칙을 따르며, 경사에서도 세계의 수평 XZ 좌표 기준이다.
- 달리기/점프/기본 공격은 **기본도형 관절 시각화**이며, 실제 발 IK나 모션 캡처 품질을 주장하지 않는다.
- 왼클릭 공격에는 공격 판정, 피해, 이펙트가 없다.
- 30° 경사에서는 발판 전개가 위험한 위치가 생길 수 있다. 고정 회전판을 새로 만든 것은 아니다.
- 장시간 직접 플레이 테스트는 진행하지 않았고 사용자가 한다. Windows 빌드/정적 분석 결과와 구분한다.
