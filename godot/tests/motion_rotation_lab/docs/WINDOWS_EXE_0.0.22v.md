# CheRPG Motion Lab 0.0.22v — 지형 접촉 관절 보정 및 계단 턱 올라가기

**Godot 4.7.2 · Windows x64 · 독립 테스트장 · Windows CompanyName=CheRPG**

## 계단 막힘 원인과 수정
- 시험 지점 10의 초기 위치가 계단 5번째 충돌 구조물 안쪽(`z=-18.0`)이었던 문제를 발견하여 **첫 계단 앞 평지 `z=-13.6`**으로 수정했습니다.
- 실제 8개 계단은 한 단의 상승 높이가 **0.16m**인 BoxShape3D입니다. Godot CharacterBody3D의 경사 처리만으로는 계단의 수직 모서리를 넘지 못하므로 **0.225m까지 턱 올라가기(step-up)**를 구현했습니다.
- 계단 전방에서 수평 이동이 막히면 **(1) 위쪽 캡슐 충돌 검사, (2) 높아진 위치에서 전방 충돌 검사, (3) 목표 발판의 표면 높이·법선 확인, (4) 원래 4m 체스 판면 이동 허용 검사**를 실시합니다. 모두 통과한 경우에만 계단 표면으로 올라갑니다.
- 경사 없는 평지나 몸 위가 막힌 구조물, 너무 높은 벽에서는 자동으로 위로 이동하지 않습니다. 기존 Ctrl 벽 등반은 독립된 기능입니다.

## 지형에 붙는 발 / 벽에 붙는 손
- 걷기·달리기·웅크리기 동안 현재 **지지하는 발(보행 주기 약 60%)**과 공중 이동하는 발을 구분합니다.
- 양쪽 발의 지면 레이캐스트로 바닥 높이와 지면 법선을 구하고, **고관절-무릎 2관절 역운동학(leg IK)**으로 발바닥을 실제 경사/계단 발판 가까이에 정렬합니다. 공중 이동 발이 바닥 속에 들어가려 할 때만 충돌을 피하도록 개입합니다.
- **허벅지·정강이·신발 길이는 고정**됩니다. IK가 도달할 수 없는 지형 접촉은 관절을 늘리는 대신 포즈 보정을 제한합니다.
- 잡을 수 있는 벽에서 손의 접촉 위치를 레이캐스트로 구하고, 어깨-팔꿈치 **2관절 역운동학(arm IK)**으로 각 손을 표면에 가까이 붙입니다. 상단 턱 넘기에는 별도의 가장자리 목표 손 위치가 사용됩니다.
- 기존 발/정강이 충돌의 무조건적인 예외 처리를 없애고, 실제 지형 위의 정상 접촉인지 깊은 관통인지 구분하는 보정 판정을 적용했습니다.

## 검증과 한계
- 코드 구조, 메시 크기 불변, Godot의 짧은 시작 검사를 통과한 후, **실제 물리 계단 시험장에서 자동 W 전진으로 계단 여러 개를 오르는 짧은 검사**도 수행합니다.
- 본 구현은 **2관절 평면 IK와 메시 근사 충돌**입니다. 3D 전신 물리 기반의 완전한 자기 충돌, 움직이는 발의 완벽한 월드 고정, 모든 지형과 모든 모션에서 절대 관통/부유가 없다는 검증은 아닙니다. 관절이 닿을 수 없는 거리에서는 모델 길이를 늘리지 않습니다.
- 주요 1분 이상 수동 플레이 테스트는 사용자 담당입니다.

## 유지된 조작
WASD: 카메라 기준 이동 / Shift: 웅크리기 / Ctrl: 달리기 또는 30~90° grabbable 벽 등반 / Ctrl+W/S/A/D: 벽 기준 상하좌우 / F 홀드: 앵커 공간 미리보기, 떼기: 설치·회수 / I: 4m 판면 **논리 이동 제약만** ON/OFF (타일 표시 유지) / 1~9,0: 시험 지점 / **0: 계단 앞에서 시작** / O: 리셋 / Space: 점프 / 마우스: 90° 카메라.

제작자 회사 이름은 Windows PE 파일 속성에 CheRPG로 기록하지만 디지털 코드서명은 미적용 상태입니다.
