# CheRPG 0.0.9v Windows 실행 안내

- Godot 4.7.2 / Windows x64 / 본편과 분리된 지형 모션 테스트.
- CheRPG-MotionLab-0.0.9v.exe를 더블 클릭하여 실행. Godot 별도 설치 불필요.
- W/A/S/D: 카메라를 기준으로 수평 이동. W는 카메라가 보는 방향.
- Shift: 달리기 / Space: 점프 / 마우스: 카메라 회전 / Esc: 포인터 캡처.
- 1~5: 시험 지형 변경 / T: 현재 지형 시작점 재설정.
- R/E/Q: 회전장치 전개/행마 방향 변경/회수 / Z/C: 신체 방향만 회전 / F1: 판면 디버그 표시.
- 2m 판면 한 칸 안에서는 이동 자유. 칸 밖으로 자발 이동할 때는 폰 행마식을 적용.
- 시작 발 위치와 지면 충돌, 카메라 기준 조작감의 **주요 플레이 테스트는 사용자 담당**.
- 게임 빌드 확인과 실제 Windows 플레이 품질 확인은 별개이다.
