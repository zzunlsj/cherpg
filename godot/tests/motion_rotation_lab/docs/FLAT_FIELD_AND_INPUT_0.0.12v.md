# CheRPG 0.0.12v 설계 변경 기록

## 100 × 100m 완전 평지
원본 독립 테스트장만 변경했다. 지형 스크립트 `test_lane.gd`를 100×100m 평평한 BoxMesh/BoxShape로 교체, 위에 독립된 경사 시험 구조물들을 배치한다. 바닥의 표면 높이는 정확히 0이고, 별도 시험 구조물을 설치하더라도 바닥 자체는 변하지 않는다. 50×50=2500 칸의 2×2m 판면 시각화를 세계 좌표 (0,0) 기준 ShaderMaterial로 구현했다. 판면 경계는 검은 선, 칸은 두 색이 교차하는 테스트용 스타일이다.

시험 시설: 8° / 15° / 30° / 45° / 60° / 75° 경사대, 90° 높이 3m 수직벽, 요철 실험지, 8단 계단. 1~9,0은 각 시험 구역으로 바로 이동하는 단축키이며 모든 구조물은 하나의 평지에 놓인다. 90°는 일반적인 바닥 경사 개념을 벗어나므로 수직 접촉을 감지한 경우에만 별도 상향 등반 시도를 한다. 90° 실제 등반 및 턱 넘기의 자연스러움은 미검증.

## 기본 입력 우선순위
최신 사용자 지정 키 배치를 우선한다. `pawn_player.cs`의 WASD/방향키, 입력 변화 보간(10/s), 마우스 왼쪽 클릭 attack, 보행 4m/s는 유지한다. 단, Unity 원본 `Shift=달리기`는 사용자의 이번 명시적인 **Shift=대시** 요청으로 교체한다. 달리기 최고속도 6m/s 원본 수치는 소스에 남겨두지만, 현재 Shift로 계속 달릴 수는 없다. Shift 대시는 0.2초 10.5m/s, 쿨다운 0.85초의 시험 값이다.

폰 내부 칸 이동은 카메라 상대 WASD; 칸 경계의 자발 이동은 세계/행마 규칙을 준수한다. 회전장치는 F 설치/회수, 사용 중 A/D는 -/+90° 방향 값만 변경하며 **신체 회전은 일으키지 않는다.** R 홀드는 지형의 네 앵커 가능 여부를 읽고 1.51m 필요 영역/2m 타일을 표시. O 현재 시험 위치 초기화. 배치/모션/등반 값은 실험용으로 세계관 설정의 확정 수치가 아니다.

## 모션
걷기·대시 중 허벅지 및 무릎 각도를 증가시키고, 점프 상승/하강에 더 큰 관절 굴곡을 사용했다. 90° 벽에는 간단한 등반 자세를 추가했다. 모델 자체는 계속 기본도형으로 남는다. 완성된 발 IK/실제 접촉 물리/애니메이션 리타게팅을 구현한 상태가 아니므로 직접 조작과 지형 충돌은 사용자가 확인해야 한다.

## 사용자 검수
- 총 바닥 가장자리에서 100×100m 크기와 2m 간격 50×50칸 표시를 확인.
- 8°부터 90°까지 구조물 접근, 오르막 지면 접촉/슬라이딩/수직벽 W 등반 확인.
- F 설치→A/D 각도 변경→F 회수. 그동안 캐릭터 몸이 회전하지 않는지 확인.
- R 길게 누르고 이동/경사/칸 경계에서 홀로그램 색과 범위를 확인.
- O 리셋과 Shift 연속/쿨다운 대시, 점프/착지 시 관절 접촉 확인.
- 시각/물리 문제 발생 시 지형 번호와 원래/원하는 동작을 기록.

본편 월드는 수정하지 않는다. 장시간 테스트는 사용자에게 위임한다.
