# CheRPG Motion Lab 0.0.18v — 벽 관통 방지 3인칭 카메라

**Godot 4.7.2 / Windows 64비트 / EXE 파일 속성의 회사 이름: CheRPG**

## 카메라 수정

- 평소에는 기존 **캐릭터로부터 6.8m 떨어진 3인칭 궤도**를 유지합니다. 마우스 움직임과 90° 수직 탑뷰 기능도 그대로입니다.
- 카메라가 가야 하는 경로에 벽, 바닥, 천장, 경사, 계단 같은 **월드 layer 1의 실제 물리 충돌 구조물**이 있으면 카메라가 해당 구조물을 통과하지 않도록 **반지름 0.23m 구체를 추적 중심에서 카메라 목표점까지 스윕**합니다.
- 충돌 시 구체와 표면 사이에 추가 **0.08m 안전 여유**를 두고 카메라를 벽 앞쪽에 배치합니다. 지형이 사라지면 원래 6.8m 거리로 부드럽게 복귀합니다.
- **카메라 이동 보간을 마친 위치에도 다시 충돌 검사를 적용**합니다. 벽 반대편에서 카메라를 돌리는 중 보간 과정 자체가 벽을 통과하는 문제도 다룹니다.
- Ctrl 등반 중에는 벽을 잡은 몸 가까이에서 충돌 스윕이 시작되지 않도록 접촉 벽 법선 바깥쪽으로 추적 시작점을 0.11m 보정합니다.
- 벽에 의해 카메라가 가까워질 때 캐릭터의 몸과 머리가 보이도록 시야각을 최대 80°로 넓히며, 원래 거리에서는 기존 65° 시야각을 사용합니다.
- 카메라의 near plane은 0.06m입니다. HUD의 **ARM 실제거리/기본거리(WALL 또는 CLEAR)**로 카메라 충돌 감지를 확인할 수 있습니다.

## 유지되는 기능

**Ctrl** 달리기 / 30°~90° 잡을 수 있는 면 등반, **Ctrl+W/S/A/D** 카메라와 무관한 벽 접선 이동, **Ctrl 단독** 벽에 매달려 정지, **Shift** 웅크리기, **I** 4m 판면의 실제 이동제약 ON/OFF(타일 무늬 유지), **F 누르기** 앵커 설치 범위 미리보기·놓기 설치/회수, **O** 리셋, **Space** 점프, 90° 카메라, 벽 상단 턱 넘기 및 애니메이션을 유지합니다.

## 사용자가 직접 수행할 주요 테스트

1. 벽을 등지고 마우스로 카메라를 180° 회전하며 **벽을 지나 반대쪽 화면으로 넘어가거나 지형 내부에서 보이는 현상**이 없는지 확인.
2. Ctrl+W로 90° 벽을 올라가면서 카메라가 벽 앞에 붙어 캐릭터가 보이는지 확인.
3. 벽에서 멀어지면 HUD의 ARM이 6.8m까지 복원되는지 확인.
4. 90° 탑뷰에서 바닥·계단·벽에 카메라가 끼거나 땅 아래로 내려가지 않는지 확인.
5. 좁은 코너나 천장 바로 아래에서 카메라가 떨리거나 캐릭터가 화면 밖으로 사라지는지 확인.
