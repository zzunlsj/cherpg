# CheRPG 0.0.10v Windows 실행 안내

- 엔진: Godot 4.7.2, Windows 64비트 독립 테스트 맵.
- 주요 변경: **모든 시험 지형을 양면 렌더링**하여 위에서 내려다보았을 때 지면이 보이지 않던 문제를 수정했다.
- 지면 메시/높이/충돌 형태, 카메라 기준 WASD, 점프, 판면 규칙, 방향 전환 장치 및 캐릭터 기본도형은 그대로 유지한다.
- EXE 파일 속성의 **회사/제작자 표시: CheRPG**. Godot의 `application/modify_resources=true`와 `application/company_name="CheRPG"`를 사용한다.
- **주의: 코드 서명 인증서는 아직 없으며, Windows UAC/SmartScreen의 검증된 '게시자'로 CheRPG가 표시되는 것은 아니다.** 이를 위해서는 실제 인증된 서명 인증서와 빌드 파이프라인의 서명 단계가 필요하다.

## 조작
W/A/S/D 카메라 기준 수평 이동, Shift 달리기, Space 점프, 마우스 카메라 회전. 1~5로 지형 전환, T 재시작, R/E/Q 회전장치, Z/C 몸만 회전, F1 판면 표시.

## 사용자가 직접 수행할 주요 검수
1. 모든 지형(평지/8°/15°/요철/30°)을 위에서 내려다볼 때 바닥이 보이는가?
2. 낮은 카메라 각도 및 뒤편 카메라에서도 갑자기 사라지는 면이 없는가?
3. 실제로 발이 지면 위에 있으며, 점프/착지 후에도 발과 지면이 자연스럽게 만나는가?
4. Windows 파일 속성 → 자세히에서 회사 표시가 CheRPG로 나타나는가?
5. W를 눌렀을 때 카메라 정면으로 움직이며, 판면 칸 경계 행마 제한은 그대로 작동하는가?

1분 이상 플레이 테스트는 사용자 담당이며 이 빌드에서는 실행하지 않는다. 기존 본편 월드/메인 소스는 수정하지 않았다.
