# CheRPG Motion Lab 0.0.14v — Windows 실행 안내

**엔진**: Godot 4.7.2 · **제작자 파일 정보**: CheRPG · **테스트장**: 100×100m, 평지 위 경사·수직벽·요철·계단.

## 이번 버전의 조작
- **WASD / 방향키**: 카메라 기준 수평 이동. **Shift**: 짧은 대시. **Space**: 점프.
- **F 누르고 있기**: 설치에 필요한 1.51m 정사각 범위, 받침 네 개, 현재 **4m×4m 판면** 테두리를 홀로그램으로 확인. 빨강: 설치 조건 불충족, 초록: 가능.
- **F 키 놓기**: 앵커 설치 또는 회수(기존 R 기능 흡수). 설치 중에는 A/D로 행마 방향을 -/+90° 바꾸며 몸 자체는 회전하지 않음.
- **I**: 판면 경계선과 체커 명암을 모두 숨기거나 다시 표시. 기본은 표시 ON.
- **O**: 현재 시험 지점 초기화. **1~9, 0**: 10개 시설 이동. **마우스**: 카메라(최대 수직 90°). **Esc**: 마우스 해제. **Z/C**: 몸만 회전. **왼클릭**: 피해 없는 공격 관절 동작.

## 판면: 정확히 4m×4m
물리 이동 판정, 현재 칸 계산, 바닥 색·경계 표시, 앵커 홀로그램의 칸 테두리를 동일하게 4m×4m 세계 원점 기준으로 바꾸었다. 100m×100m 평지는 **25×25=625개 판면**이다. 체스 세계관에서 판면은 보이지 않으므로 실제 게임에서는 I로 끄는 것을 기본으로 검토한다.

## 잡을 수 있는 30° 이상 벽 등반
- 시험 경사대 중 30°/45°/60°/75°와 90° 벽만 **`cherpg_grabbable` 그룹**으로 표시한다. 8°/15° 경사는 이 그룹에 속하지 않는다.
- W로 벽을 향해 진행하고 **0.95m 이내에 표면이 닿는 경우**, 레이캐스트 지면 법선으로 30°~90° 경사도를 확인한 뒤 접촉 등반으로 바꾼다.
- 등반 운동은 표면을 따라 위로 진행하는 접선 속도 및 약한 부착 압력으로 구성한다. 90° 시험벽의 상단에는 착지판/턱 넘기 동작이 있다.
- **주의**: 등반 애니메이션/90° 턱 넘기/경사에서의 실제 물리 안정성은 아직 사용자 플레이 미검증이다. 이 구성은 개발 시험 로직이다.

## 실제 보행 참고
- 지지기 약 60%, 유각기 약 40%의 보행 주기를 기반으로 발 착지→하중 지지→발끝 밀기→다리 전진을 나누어 기본도형 고관절·무릎·발목·팔에 적용.
- 보행 무릎은 착지 직후 약 15~20°, 유각기에는 최대 약 60°까지 굽히는 동작을 참고했으나 1.55m 기본도형에 맞춰 보정했다.
- 자료: NIH PMC10113840 (보행주기), NIH PMC2953341 (무릎 각도), University of Oklahoma gait terminology (https://www.ouhsc.edu/bserdac/dthompso/web/gait/terms.htm).
- 현재 발 접촉 IK나 모션캡처 데이터는 사용하지 않는다. 따라서 미끄러짐 등은 사용자에게 검수받는다.

## 검수 책임과 게시자
- 1분 이상 걸리는 주요 테스트는 **사용자 직접 수행**. 빌드에서는 정적 검사, 짧은 임포트/시작 확인, Windows EXE 생성 및 CompanyName 검사만 진행.
- Windows 실행파일의 회사 메타데이터는 CheRPG로 기록. 실제 서명된 신뢰 게시자 표시에는 별도 코드서명 인증서가 필요하다.
