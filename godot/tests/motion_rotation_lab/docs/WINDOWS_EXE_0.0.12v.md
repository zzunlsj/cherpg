# CheRPG — Godot 4.7.2 / 0.0.12v Windows 테스트장

**개발 빌드, Windows x64.** 실행 파일 `CheRPG-MotionLab-0.0.12v.exe`를 실행하세요. 별도 Godot 설치가 필요하지 않습니다.

## 조작
- W / A / S / D: 카메라가 바라보는 수평 방향을 기준으로 자유로운 칸 내부 이동.
- Shift: 한 번 누르면 **0.20초 동안 10.5m/s 대시**, 재사용 대기시간 0.85초. Shift 지속 달리기 기능을 대시로 교체.
- Space: 가변 높이 점프 (누르는 시간에 따라 높이 차이).
- F: 허리 회전장치 앵커 설치 또는 회수. 설치·회수 중에는 재입력을 기다립니다.
- **앵커 설치 완료 후 A: 행마 방향 -90°, D: +90°**. 앵커 사용 중 이동은 잠금.
- **R 길게 누르기:** 현재 2m×2m 칸과 지면 설치에 필요한 1.51m×1.51m 공간, 네 받침 위치를 투명 홀로그램으로 표시. 초록색은 설치 조건 충족, 붉은색은 불가.
- O: 현재 선택된 시험 지점으로 초기화.
- 1~9, 0: 평지, 8°, 15°, 30°, 45°, 60°, 75°, 90° 벽, 요철, 계단의 10개 시험 위치 이동.
- F1: 판면 경계 강조.
- 마우스: 카메라 회전, 왼쪽 클릭: 피해 없는 팔 공격 포즈, Esc: 커서 잠금 전환.
- Z/C: 신체만 좌우 90° 회전. 행마 방향은 별도.

## 지형과 판면
- **완전 평평한 바닥 100m × 100m**, 기준 표면 y=0. **50 × 50 = 2500개 2m × 2m** 판면으로 명암과 경계선을 표시.
- 평지 위에 8°, 15°, 30°, 45°, 60°, 75° 경사대, 90° 수직벽(높이 3m), 요철 시험 영역, 계단을 각각 별도 배치.
- 일반 경사는 Godot CharacterBody3D의 89.9° floor_max_angle까지 허용하도록 설정하고, **정확히 90°인 수직벽은 접촉 레이캐스트 + W 상향 이동**의 별도 시험 기능이다. 이는 아직 품질 검증된 완전한 등반 시스템이 아니다.
- 판면은 개발용 시각화다. 정사에서는 보이지 않는 2m 격자다.
- 전진이 허용된 방향으로만 칸 경계를 넘어갈 수 있다는 **폰 행마 제약**은 유지된다.

## 제작자와 검증
- Windows 파일 VERSIONINFO `CompanyName=CheRPG`. 인증된 디지털 서명은 별도이며 현재 미적용.
- 자동 빌드는 Godot 임포트, 몇 프레임의 파싱·시작 확인과 EXE 생성 및 파일 검증만 수행한다.
- **1분 이상 걸리는 실제 이동, 벽 등반, 점프, 앵커·홀로그램 조작/품질 테스트는 사용자가 직접 수행한다.**
