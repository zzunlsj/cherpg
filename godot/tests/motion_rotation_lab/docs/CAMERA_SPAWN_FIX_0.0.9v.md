# CheRPG 0.0.9v — 지면 스폰·카메라 기준 WASD 수정

Godot 4.7.2 / 본편 월드와 분리된 모션 테스트 맵.

## 시작 위치 수정

기존 폰 충돌 캡슐의 중심은 발 원점보다 0.765m 높았고 캡슐의 전체 높이는 1.43m였다. 캡슐 하단이 원점보다 +0.05m에 있으므로 바닥에 안착하며 캐릭터 원점이 내려가면 일부 발 도형이 지면에 묻힐 수 있었다.

- 캡슐 중심을 높이의 절반(0.715m)으로 수정해 바닥을 원점에 일치시켰다.
- 기본도형 형태를 유지하면서 양 발의 도형 위치를 0.032m 낮춰 바닥 기준에 맞췄다.
- 최초 시작도 숫자키 지형 이동 및 T 리셋과 동일한 _teleport_to_lane(0) 경로를 사용하며, 지형 height_at 값에서 +0.20m 여유를 두고 시작해 지형 안에 겹쳐 생성되지 않도록 했다.

## 카메라 기준 이동

- 매 물리 프레임 Camera3D.global_transform.basis.z의 반대 방향을 평면(XZ)에 투영해 W 방향으로 사용한다.
- D는 카메라 우측, S는 후방, A는 좌측이다. 카메라의 상하 피치는 수평 이동에 영향을 주지 않는다.
- 기존 C# 원본의 10/s 입력 보간, 걷기 4m/s, 달리기 6m/s, 점프 및 감속은 유지한다.
- 플레이어 몸 방향과 세계 행마 기준 방향을 분리한다. 카메라를 돌려도 heading_index는 바뀌지 않는다.
- 2m 타일 **안에서는 자유 이동**하지만 다른 칸으로 넘어갈 때는 폰 행마식 전진 방향을 검사한다.

## 사용자 테스트

1. 최초 실행, T 초기화, 1~5 지형 변경 후 캐릭터가 지면에 묻히지 않는지 확인.
2. 마우스로 카메라를 90°·180° 돌리고 W 이동 방향을 확인.
3. 카메라를 위·아래로 돌려도 W 입력에서 수직 상승/하강이 생기지 않는지 확인.
4. A/D/S 키가 카메라 기준 좌우·후방을 가리키는지 확인.
5. 행마상 금지된 칸 경계를 넘을 수 없는지 확인.

코드와 1분 미만 정적 검사를 실시했으며, **1분 이상 주요 실플레이 테스트는 사용자가 직접 수행**한다.
