# CheRPG Motion Lab 0.0.15v — Windows 실행 안내

Godot 4.7.2, Windows 64비트, 회사/제작자 파일 정보: **CheRPG**. 독립 실험용 100m×100m 시험장. 바닥 판면은 4m×4m, 총 25×25=625칸입니다.

## 최신 조작
- **W/A/S/D** 또는 방향키: 카메라 기준 이동.
- **Ctrl (누르는 동안)**: 최대 6m/s 달리기. 전방에 **잡을 수 있는(grabbable) 30°~90° 경사/벽**이 가까이 있으면 **Ctrl+W**로 등반 시도. Ctrl을 떼면 달리기·등반 입력 해제.
- **Shift (누르는 동안)**: 웅크리기. 이동 속도 상한 약 1.8m/s; 캐릭터 모습뿐 아니라 충돌 캡슐 높이도 1.43m → 1.02m로 줄어듭니다. 머리 위에 장애물이 있으면 키를 떼도 일어서지 못합니다. Ctrl과 Shift를 같이 누르면 **웅크리기 우선**.
- **I**: 보이지 않는 4m 판면의 **실제 행마 이동 제약만** ON/OFF. 바닥의 밝고 어두운 타일 패턴과 선은 **항상 그대로 보입니다.**
- **F 누르고 있기**: 현재 칸과 앵커 설치 필요 공간 미리보기. **F 놓기**: 앵커 설치/회수. 앵커 설치 중 A/D는 행마 방향 ±90°.
- **Space**: 가변 점프. **O**: 현재 시험 지점 리셋. **1~9,0**: 시험 지점 선택. **마우스**: 카메라 회전(최대 90° 탑뷰), **Esc**: 포인터 제어 전환. **왼클릭**: 피해 없는 기본 공격 자세.

## 보행·점프·등반 관절 보정
기존 기본도형 폰 리그에서 `knee.rotation.x`에 **양수 각도를 주면 정강이가 앞쪽(-Z)으로 꺾이는 것**을 발견해, 무릎 굽힘을 **음수 각도(발꿈치 쪽 +Z)**로 교정했습니다.

걷기, 뛰기, 웅크리기, 등반과 60% 지지기/40% 유각기 보행 주기 모두 같은 무릎 구부림 방향을 사용합니다. 전체 애니메이션 마지막에는 무릎 0~약 95° 뒤쪽 굽힘, 고관절·발목·팔·상체 범위 제한을 강제하여 관절 반대 방향 꺾임을 방지합니다. 기본도형이며 실제 발 접촉 IK·완성 모션캡처는 없습니다.

## 주의
- 세계관에서 보이지 않는 판면의 *행마 제한을 임시 해제하는 개발용 치트*가 I키입니다. 실제 판면 타일 무늬는 개발 편의 표시로 유지됩니다.
- I=OFF에서도 일반 Godot 지형 충돌/중력/벽 접촉 등 **물리 충돌까지 사라지는 것은 아닙니다**. 행마 방향에 따른 **칸 경계 통과 제한만** 무시합니다.
- 90° 벽 상단 턱 넘기·실제 보행 품질·머리 위 장애물의 웅크리기 충돌 등은 아직 사용자의 실플레이 검수가 필요합니다.
- Windows 회사 파일 정보는 CheRPG이나 디지털 코드 서명은 아직 없습니다. 서명 검증 게시자 표시가 자동으로 생기지 않습니다.
- 1분 이상 소요되는 주요 플레이 테스트는 사용자가 직접 수행합니다. 빌드는 짧은 스크립트 검사, 에디터 임포트, 몇 프레임 시작 확인, EXE 패키징만 진행합니다.
