# CheRPG — 폰의 방향 전환 장치 0.0.2v (기본도형 설계)

이 모델은 **세부 실루엣을 조형하지 않은 기본도형 블록아웃**이다. 기존 Pawn 0.0.1v의 몸체는 변경하지 않는다.

## 최신 세계관 기준

2026-10-07 이후의 후속 설정을 우선한다. 장치는 **허리 벨트 → 수평 확장 링 → 수직 앵커 하강 → 행마 방향 변경** 순으로 동작한다. 캐릭터의 신체를 돌리지 않으며, 몸이 바라보는 방향과 행마의 '앞'은 구별된다. 이전의 '몸을 회전시킨다'는 설명을 구현하지 않는다.

## 주요 부품

- `DEVICE_00_WaistMount`: 상시 착용한 허리 링
- `DEVICE_02_ExpandableRing`: 반지름 0.232m → 0.68m로 확장
- `ACTUATOR_01..04`: 바깥 링을 밀어내는 방사형 슬라이드
- `ANCHOR_01..04`: 대각 네 곳에서 수직 하강하는 두 단계의 앵커와 받침
- `DEVICE_CTRL_HeadingOnly`: 몸과 독립적으로 움직이는 방향 표지 (기본 -Y에서 +X로 90도 전환)
- 모델은 링, 원기둥, 상자, 원뿔 등의 기본 기하 도형으로만 구성한다.

## Blender Tool 실행

저장소의 기존 `CheRPG Blender Tool`을 수정하지 않고 사용한다.

1. GitHub Actions → **CheRPG Blender Tool** → **Run workflow**
2. 브랜치: `feature/pawn-primitive-blockout-0.0.1v`
3. action: `run_script`
4. script_path: `production/pawn_protagonist/modeling/pawn_direction_device_0_0_2v.py`
5. `cherpg-blender-tool-result` 아티팩트에서 Blender 프로젝트, 장치 애니메이션 GLB, 세 가지 정적 GLB, 렌더를 받는다.

타임라인 프레임: 1=수납, 30=링 전개, 50=앵커 접지, 80=행마 기준 방향 변경, 100=유지.

GitHub 스크립트의 GLB **출력에는 캐릭터 모델을 포함하지 않는다**. .blend 안의 단순 캐릭터는 크기·구조 참고용 미리보기 전용이다. 별도로 전달하는 채팅 산출물에는 이전 캐릭터 GLB의 30개 기존 메시를 재사용해 장착 모습을 보여주는 조합 GLB도 있다.

## 검증 상태

로컬에서 Python 문법을 검사하고, 별도로 만든 정적 trimesh GLB를 다시 읽어 비교해 1.55m 높이와 원래 캐릭터 메시 불변을 확인했다. **Blender Actions 실제 실행, 애니메이션 GLB 내보내기, Godot 로드/충돌 테스트는 아직 수행하지 않았다.** 링/지면 앵커 모델을 실시간 판면 좌표계와 연결하는 코드는 다음 구현 과제다.
